# agent-skills

My skills for AI agents.

## Install

Claude Code:

```
/plugin marketplace add https://github.com/stitcombe/agent-skills.git
/plugin install skills@stitcombe
```

Other agents (Codex, Cursor, etc.) via [skills](https://github.com/vercel-labs/skills):

```
npx skills add https://github.com/stitcombe/agent-skills.git
```

Update in Claude Code with `/plugin marketplace update stitcombe`.
